# Microsoft OAuth2 认证准备

Outlook 批量收件台不内置开发者身份，也不接收邮箱密码。你需要在自己的 Microsoft Entra 租户中注册应用，并仅为自己实际使用的账号授予委托权限。

## 最小权限

1. 在 Microsoft Entra 管理中心注册应用，记录 Application (client) ID。
2. 选择与你账号类型一致的受支持账户范围；个人 Outlook.com 通常使用 `consumers` 租户入口。
3. 为“Office 365 Exchange Online”添加委托的 `IMAP.AccessAsUser.All` 权限，并在授权时请求 `offline_access`。
4. 使用 Microsoft 支持的授权码或设备授权流程取得 refresh token。优先使用 Microsoft Authentication Library (MSAL)，不要从不明网站购买、交换或生成令牌。
5. 在 Outlook.com 设置中启用 IMAP。Microsoft 当前说明 IMAP/POP 默认可能关闭。

## 凭据保管

- refresh token 等同于长期登录能力，不要提交到 Git、聊天、截图、日志或云剪贴板。
- 示例中的地址、UUID 与占位文字都不能替代真实授权。
- 如果令牌曾进入公开仓库，仅删除文件不够；必须在 Microsoft 账号或 Entra 应用中撤销/轮换，并清理所有 Git 历史和发布资产。
- 完成取件后关闭页面；不要把账号文本或导出文件留在共享电脑上。
