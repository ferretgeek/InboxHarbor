# 部署指南

## 本机（推荐）

```powershell
python -m inbox_harbor
```

默认入口是 `http://127.0.0.1:4174`。服务只接受本机回环连接，适合个人电脑使用。

## 远程 Linux + SSH 隧道（最稳妥）

在服务器仍然只监听 `127.0.0.1`：

```bash
python -m inbox_harbor --host 127.0.0.1 --port 4174
```

在自己的电脑建立隧道：

```bash
ssh -L 4174:127.0.0.1:4174 your-user@your-server
```

然后仅访问本机的 `http://127.0.0.1:4174`。SSH 负责加密，服务端口无需暴露公网。

## Docker Compose

Compose 文件把宿主端口绑定在回环地址，并以只读文件系统、零 Linux capabilities、进程/内存/CPU 限额运行。

```bash
export INBOXHARBOR_ACCESS_TOKEN="$(python -c 'import secrets; print(secrets.token_urlsafe(32))')"
docker compose up --build -d
```

访问密钥只保留在你的部署环境中，不要写进仓库或截图。即使端口仅回环，容器内监听为 `0.0.0.0`，所以应用仍要求这把密钥。

## HTTPS 反向代理

确需经域名访问时：

1. 设置至少 32 字符的 `INBOXHARBOR_ACCESS_TOKEN`。
2. 将准确域名写入 `INBOXHARBOR_ALLOWED_HOSTS`，多个值用逗号分隔。
3. 只让 Nginx、Caddy 或 Cloudflare Tunnel 连接应用端口；外部必须使用 HTTPS。
4. 在页面右上角临时输入访问密钥。它只留在当前页面内存，不写 `localStorage`。
5. 代理不得记录请求体或 `X-InboxHarbor-Key`；不要启用第三方分析、远程脚本或会话录制。

示例：

```bash
INBOXHARBOR_ACCESS_TOKEN='<generate-at-deploy-time>' \
INBOXHARBOR_ALLOWED_HOSTS='mailbox.example.com' \
python -m inbox_harbor --host 0.0.0.0 --port 4174
```

## 健康检查与升级

`GET /api/health` 只返回版本、运行状态和保护模式，不包含账号信息。升级前保留旧镜像标签作为回滚点；项目本身没有数据库或数据迁移。
