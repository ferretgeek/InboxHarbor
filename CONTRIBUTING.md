# Contributing

Thank you for helping make this project safer and calmer to use.

1. Open an issue for product or behavior changes; use private vulnerability reporting for security findings.
2. Use synthetic `example.com` / `example.net` identities only. Never attach a real account line, token, message, log, screenshot, host, or tenant.
3. Keep runtime dependencies at zero unless a new dependency has a clear security and maintenance benefit.
4. Run Python tests, browser-core tests, Ruff, Bandit, dependency audit, and secret scans before a pull request.
5. Preserve OAuth-only authentication, fixed Microsoft endpoints, memory-only credentials, safety limits, all four themes, responsive behavior, and bilingual docs.

中文：普通功能问题可开 Issue；安全问题请使用私密漏洞报告。所有示例与截图必须使用完全合成的数据。
